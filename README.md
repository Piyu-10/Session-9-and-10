# ✦ Piyu Gupta — Personal Profile Website

A modern, elegant, responsive, and interactive personal profile website created using **HTML, CSS, and JavaScript**.

The website represents my **personality, academic background, technical journey, skills, interests, and career aspirations** through a clean and bold visual design.

---

## 🌐 Project Overview

This project is a personal portfolio/profile webpage designed to introduce **Piyu Gupta**, a B.Tech Computer Science Engineering student at **JECRC University**.

The website focuses on presenting both sides of my journey:

* 👩‍💻 My technical and academic growth
* ✨ My personality and personal interests

The design follows a **minimal, bold, elegant, and professional** approach while adding interactive elements to make the website more engaging.

---

## 🎯 Objectives

The main objectives of this project are:

* Create a professional personal profile webpage.
* Introduce myself and my background.
* Highlight my personality traits.
* Showcase my technical journey and skills.
* Present my interests beyond technology.
* Create a responsive website that works on different screen sizes.
* Implement an interactive **Dark/Light Mode toggle**.
* Practice HTML, CSS, and JavaScript together.
* Build a foundation for a future professional portfolio.

---

## ✨ Features

### 🌓 Dark / Light Mode

The website includes a theme toggle button at the top of the page.

Users can switch between:

* 🌙 Dark Mode
* ☀️ Light Mode

The selected theme is stored using **Local Storage**, so the website remembers the user's preference even after refreshing the page.
